**เรื่อง** ขออนุมัติเปิดเผยข้อมูลสรุปการจ่ายยาผ่านระบบ RxMuk API และกำหนดแนวทางแบ่งปันข้อมูลรายละเอียด

**ผ่าน** เจ้าหน้าที่คุ้มครองข้อมูลส่วนบุคคล (DPO)

## 1. ความเป็นมา

ระบบ RxMuk ใช้ข้อมูลการจ่ายยาผู้ป่วยนอกจาก HDC (แฟ้ม tmp_drug_opd) ของหน่วยบริการทุกแห่งในจังหวัด เพื่อวิเคราะห์งบประมาณยา ราคายา การใช้ยาอย่างสมเหตุผล และคุณภาพข้อมูล ปัจจุบันมีหน่วยงานและระบบอื่นต้องการนำข้อมูลไปใช้ต่อ เช่น ระบบคลังยา งานแผนงบประมาณ และรายงานผู้บริหาร จึงพัฒนาช่องทางแลกเปลี่ยนข้อมูล (API) เป็น 2 ระดับ

## 2. ข้อมูลที่ขออนุมัติ

| ระดับ | เนื้อหา | ผู้เข้าถึง | การคุ้มครองข้อมูล |
|---|---|---|---|
| **ก. สาธารณะ** | ยอดรวมรายเดือนต่อรายการยา ต่ออำเภอ ต่อหน่วยบริการ และรายยาในแต่ละพื้นที่ ได้แก่ จำนวนจ่าย มูลค่า ราคาต่อหน่วย และคะแนนคุณภาพข้อมูล | ทุกคน ไม่ต้องลงทะเบียน | ไม่มีข้อมูลรายบุคคล · รายการยาที่จ่ายน้อยกว่า 5 ครั้งต่อพื้นที่ถูกรวมเป็น "อื่นๆ" เพื่อป้องกันการระบุตัวบุคคล |
| **ข. หน่วยงานที่ได้รับอนุญาต** | ข้อมูลรายครั้งที่จ่าย (เดือน วันที่ หน่วยบริการ รหัสและชื่อยา จำนวน มูลค่า ต้นทุน) | เฉพาะหน่วยงานที่ทำข้อตกลงแบ่งปันข้อมูล ใช้ key แยกรายหน่วยงาน มีวันหมดอายุ | ไม่ส่งรหัสผู้ป่วย (pid) · ถ้าจำเป็นต้องนับจำนวนผู้ป่วย ส่งเป็นรหัสที่เข้ารหัสทางเดียว ย้อนกลับเป็นตัวตนไม่ได้ · บันทึกทุกการเรียกใช้ · ยกเลิก key ได้ทันที |

## 3. ประเด็นที่ขอให้พิจารณา

1. อนุมัติการเปิดเผยข้อมูลระดับ ก. เป็นสาธารณะ
2. การเปิดเผย **ต้นทุนยา / ราคาจัดซื้อต่อหน่วย** ในระดับ ก.
   ☐ อนุมัติ  ☐ ไม่อนุมัติ (ระบบปิดคอลัมน์ต้นทุนได้ทันที)
3. เกณฑ์ขั้นต่ำการรวมข้อมูล 5 ครั้งต่อพื้นที่
   ☐ เห็นชอบ  ☐ ปรับเป็น ……… ครั้ง
4. อนุมัติแนวทางระดับ ข. โดยต้องมีข้อตกลงแบ่งปันข้อมูล (Data Sharing Agreement) ระบุวัตถุประสงค์ ระยะเวลา ผู้รับผิดชอบ มาตรการรักษาความปลอดภัย และการทำลายข้อมูลเมื่อสิ้นสุด
5. มอบหมายผู้มีอำนาจออก key และทบทวนบันทึกการใช้งานทุก ……… เดือน

## 4. ข้อกฎหมายและมาตรการ

- ข้อมูลสุขภาพเป็นข้อมูลส่วนบุคคลอ่อนไหวตาม พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 มาตรา 26 ระดับ ก. เป็นข้อมูลนิรนามแบบรวมยอด ระดับ ข. ไม่มีตัวระบุบุคคลโดยตรง และเปิดเฉพาะผู้ได้รับอนุญาตตามวัตถุประสงค์ที่ตกลงกัน
- ปฏิบัติตามแนวทางการใช้ข้อมูล HDC ของกระทรวงสาธารณสุข
- ข้อมูลเก็บบน Supabase ส่งผ่าน HTTPS ทุกการเรียกใช้ระดับ ข. ถูกบันทึก (หน่วยงาน เวลา เงื่อนไข จำนวนแถว)

### ภาคผนวก: ข้อตกลงแบ่งปันข้อมูล (สาระสำคัญขั้นต่ำ)

1. คู่สัญญาและผู้รับผิดชอบข้อมูลของแต่ละฝ่าย
2. วัตถุประสงค์การใช้ข้อมูล ห้ามใช้นอกวัตถุประสงค์
3. ขอบเขตข้อมูล (เดือน พื้นที่ รายการยา) และระยะเวลา (ตรงกับอายุ key)
4. ห้ามพยายามระบุตัวบุคคล ห้ามเชื่อมโยงกับข้อมูลอื่นเพื่อระบุตัวตน ห้ามส่งต่อบุคคลที่สาม
5. มาตรการรักษาความปลอดภัยของผู้รับ: เก็บ key เป็นความลับ จำกัดผู้เข้าถึง
6. แจ้งเหตุละเมิดภายใน 72 ชั่วโมง
7. ทำลายข้อมูลเมื่อสิ้นสุดข้อตกลง และแจ้งยืนยัน
8. สิทธิยกเลิก key และตรวจสอบบันทึกการใช้งานของ สสจ.
