คู่มือ RxMuk API

ข้อมูลสรุปการจ่ายยารายเดือน จังหวัดมุกดาหาร จาก HDC (tmp_drug_opd) สำหรับนำไปใช้ใน Excel, Google Sheets หรือระบบอื่น

สรุปสั้น: เปิดลิงก์ได้เลย ไม่ต้องมีบัญชี ไม่ต้องใช้ key ข้อมูลมีชื่อยา จำนวน มูลค่า ต้นทุน และราคาต่อหน่วย แยกตามยา อำเภอ หน่วยบริการ และรายยาในแต่ละพื้นที่ เป็นยอดรวม ไม่มีข้อมูลรายบุคคล ข้อมูลอัปเดตเองทุกครั้งที่ผู้ดูแลนำเข้าข้อมูลเดือนใหม่
  1. ลิงก์ข้อมูลทั้งหมด
  2. ใช้กับ Google Sheets
  3. ใช้กับ Excel
  4. สำหรับนักพัฒนา (JSON)
  5. ความหมายของแต่ละคอลัมน์
  6. เงื่อนไขการใช้ข้อมูล · เวอร์ชัน
  7. คำถามที่พบบ่อย

2. ใช้กับ Google Sheets (ไม่ต้องเขียนโค้ด)

  1. เปิด Google Sheets ใหม่ คลิกเซลล์ A1
  2. พิมพ์สูตรนี้ แล้วกด Enter 
    =IMPORTDATA("https://vbxijqbgwgippdrhsjnb.supabase.co/storage/v1/object/public/rxmuk-public/drugs/2026-09.csv")
  3. ข้อมูลจะเต็มตารางเอง และ Google Sheets จะดึงข้อมูลใหม่ให้เป็นระยะ

วิเคราะห์รายพื้นที่: ใช้ district_drugs แล้วทำ Pivot table (แถว = ยา, คอลัมน์ = อำเภอ, ค่า = value หรือ amount) จะเห็นว่ายาแต่ละตัวใช้ในอำเภอไหนมาก และราคาต่อหน่วยต่างกันแค่ไหน

เปลี่ยน drugs เป็น districts, hospitals, district_drugs หรือ hospital_drugs และเปลี่ยนเดือนได้ตามต้องการ ถ้าใช้ trend/drugs.csv จะได้ตารางยาคูณเดือน เอาไปทำกราฟได้ทันที

3. ใช้กับ Excel

วิธีง่าย: ดาวน์โหลดไฟล์

เปิดลิงก์ .csv ในเบราว์เซอร์ ไฟล์จะดาวน์โหลดมา ดับเบิลคลิกเปิดด้วย Excel ได้เลย ภาษาไทยแสดงถูกต้อง

วิธีที่อัปเดตได้: Power Query

  1. Excel แท็บ Data > From Web
  2. วางลิงก์ .csv ที่ต้องการ แล้วกด OK
  3. กด Load ข้อมูลจะเป็นตาราง ครั้งต่อไปกด Data > Refresh All เพื่อดึงข้อมูลล่าสุด

4. สำหรับนักพัฒนา (JSON)

เป็นไฟล์ JSON ธรรมดา เรียกด้วย HTTP GET อนุญาต CORS เรียกจากเบราว์เซอร์ได้ ดู schema ทั้งหมดและลองเรียกได้ที่ Swagger UI (spec: openapi.json)

ขั้นตอนที่แนะนำ

  1. อ่าน index.json เพื่อดูว่ามีเดือนไหน และ updated_at ล่าสุดเมื่อไร
  2. ใช้ลิงก์ใน months[].files ดึงเฉพาะไฟล์ที่ต้องการ
  3. ถ้าจะตรวจว่ามีข้อมูลใหม่ไหม ให้เทียบ updated_at ไม่ต้องดึงทุกไฟล์ซ้ำ
curl -s ".../rxmuk-public/index.json"

// JavaScript
const base = "https://vbxijqbgwgippdrhsjnb.supabase.co/storage/v1/object/public/rxmuk-public";
const index = await (await fetch(`${base}/index.json`)).json();
const latest = index.months.at(-1);
const hospitals = await (await fetch(latest.files.hospitals.json)).json();

# Python
import requests
base = "https://vbxijqbgwgippdrhsjnb.supabase.co/storage/v1/object/public/rxmuk-public"
index = requests.get(f"{base}/index.json", timeout=30).json()
drugs = requests.get(index["months"][-1]["files"]["drugs"]["json"], timeout=30).json()

n8n: ใช้ node HTTP Request แบบ GET กับลิงก์ด้านบนได้เลย ไม่ต้องตั้งค่า credential

5. ความหมายของแต่ละคอลัมน์

คอลัมน์ความหมาย
didstdรหัสยามาตรฐาน 24 หลัก
dnameชื่อยา
amp_code, amp_nameรหัสและชื่ออำเภอ
hospcode, hospnameรหัส 5 หลักและชื่อหน่วยบริการ
rowsจำนวนแถวข้อมูล (จำนวนครั้งที่บันทึกการจ่าย)
patientsจำนวนผู้ป่วยไม่ซ้ำ (นับจากรหัสผู้ป่วยในเดือนนั้น ไม่เปิดเผยรหัส) · ว่าง = น้อยกว่า 5 คน
value_per_patientมูลค่าเฉลี่ยต่อผู้ป่วย 1 คน = value ÷ patients
patients_per_1000(districts) ผู้ป่วยที่ได้รับยาต่อประชากร 1,000 คน
amountจำนวนที่จ่ายรวม (หน่วยของยานั้น)
valueมูลค่า / ราคาขายรวม (บาท) ปัดทศนิยม 2 ตำแหน่ง
costต้นทุนรวม (บาท)
unit_priceราคาขายเฉลี่ยต่อหน่วย = value ÷ amount
unit_costต้นทุนเฉลี่ยต่อหน่วย = cost ÷ amount (ว่าง = ไม่มีการจ่าย)
value_YYYY-MMในไฟล์แนวโน้ม: มูลค่าของเดือนนั้น (0 = ไม่มีการจ่าย)
suppressed_itemsเฉพาะแถว "อื่นๆ": จำนวนรายการยาที่ถูกรวมไว้ในแถวนี้
groupกลุ่มยา: dm เบาหวาน, ht ความดัน, lip ไขมัน, antibiotic ยาปฏิชีวนะ, high_alert ยาความเสี่ยงสูง, other อื่นๆ (จัดกลุ่มจากรหัสยา ครอบคลุมเฉพาะยาหลัก)
antibiotic, high_alerttrue/false เป็นยาปฏิชีวนะ / ยาความเสี่ยงสูง (HAD)
ed_listtrue = อยู่ในบัญชียาหลัก, false = นอกบัญชี, ว่าง = ผู้ดูแลยังไม่ได้นำเข้าบัญชียาหลัก
population(districts) ประชากรของอำเภอ
value_per_capita, amount_per_1000(districts) มูลค่าต่อประชากร 1 คน / จำนวนจ่ายต่อประชากร 1,000 คน ใช้เทียบอำเภอเล็กกับใหญ่
missing_did, invalid_did, zero_price(hospitals) จำนวนแถวที่ไม่มีรหัสยา / รหัสยาไม่ครบ 24 หลัก / ราคาเป็น 0
quality_score(hospitals) คะแนนคุณภาพข้อมูล 0-100 = แถวที่ถูกต้อง ÷ ทั้งหมด

ผู้ดูแลเลือกได้ว่าจะเผยแพร่คอลัมน์กลุ่มไหน (เช่น ต้นทุน จำนวนผู้ป่วย) และไฟล์ไหน คอลัมน์ที่ไม่ได้เผยแพร่จะไม่มีในไฟล์เลย ดูรายการได้จาก excluded_fields และไฟล์ที่มีจาก views ใน index.json โค้ดที่อ่านข้อมูลควรรองรับกรณีคอลัมน์หายไป

เงื่อนไขการใช้ข้อมูล

  • เป็นข้อมูลสรุปจาก HDC ณ วันที่ใน updated_at และอาจมีการแก้ไขภายหลัง
  • เป็นยอดรวมเท่านั้น ไม่มีข้อมูลรายบุคคล ห้ามนำไปใช้เพื่อระบุตัวบุคคล
  • เพื่อคุ้มครองความเป็นส่วนตัว ในไฟล์ district_drugs และ hospital_drugs ยาที่จ่ายน้อยกว่า 5 ครั้ง หรือผู้ป่วยน้อยกว่า 5 คน ในพื้นที่นั้นจะถูกรวมเป็นแถว "อื่นๆ (รวมยาที่จ่ายน้อยกว่า 5 ครั้ง)" ยอดรวมของพื้นที่จึงยังถูกต้อง แต่จะไม่เห็นยาตัวนั้นแยกออกมา
  • เมื่อนำไปใช้ โปรดอ้างอิงแหล่งที่มา: RxMuk จังหวัดมุกดาหาร

เวอร์ชันและการเปลี่ยนแปลง

ระบบที่ดึงข้อมูลอัตโนมัติควรตรวจ schema_version ใน index.json ถ้าเลขหน้าจุดเปลี่ยน แปลว่าโครงสร้างเปลี่ยนแบบที่อาจกระทบโค้ดเดิม

เวอร์ชันเปลี่ยนอะไร
1.6ผู้ดูแลเลือกเผยแพร่บางกลุ่มฟิลด์หรือบางไฟล์ได้ ดูว่าอะไรไม่ได้เผยแพร่จาก excluded_fields และไฟล์ที่มีจาก views ใน index.json
1.5เพิ่ม patients, value_per_patient ทุกไฟล์ และ patients_per_1000 ใน districts · แถวรายยาในพื้นที่ต้องมีทั้ง ≥ 5 ครั้งและ ≥ 5 คน จึงแสดงแยก
1.4เพิ่ม group, antibiotic, high_alert, ed_list ในไฟล์รายยา · ค่าต่อประชากรใน districts · คะแนนคุณภาพข้อมูลใน hospitals (เพิ่มคอลัมน์เท่านั้น โค้ดเดิมใช้ต่อได้)
1.3รวมรายการที่น้อยกว่า 5 ครั้งเป็น "อื่นๆ" (suppressed_items), เพิ่ม schema_version, terms, includes_cost ใน index · เดือนที่เผยแพร่ไว้ก่อนยังอยู่ใน index
1.2เพิ่ม cost, unit_price, unit_cost, ไฟล์ district_drugs และ hospital_drugs
1.1ไฟล์แยกตามมุมมอง JSON/CSV และไฟล์แนวโน้ม
1.0เริ่มต้น: index.json และ summary/

6. คำถามที่พบบ่อย

เปิดลิงก์แล้วขึ้น Object not found / error 400

ยังไม่มีข้อมูลเดือนนั้น หรือพิมพ์เดือนเป็น พ.ศ. (ต้องเป็น ค.ศ. เช่น 2026-09) ดูเดือนที่มีได้จาก index.json

ข้อมูลอัปเดตเมื่อไร

ทุกครั้งที่ผู้ดูแลระบบนำเข้าข้อมูลขึ้น Cloud ดูเวลาล่าสุดได้จาก updated_at ใน index.json ไฟล์อาจถูกแคชไว้ไม่เกิน 5 นาที

มีข้อมูลรายผู้ป่วยไหม

ไม่มี API นี้มีเฉพาะยอดรวม ถ้าต้องการข้อมูลละเอียดกว่านี้ ติดต่อผู้ดูแลระบบ RxMuk

ตัวเลขไม่ตรงกับ HDC

ตัวเลขมาจากไฟล์ที่นำเข้า RxMuk ณ วันที่ใน updated_at ถ้า HDC มีการแก้ข้อมูลภายหลัง ต้องรอให้ผู้ดูแลนำเข้ารอบใหม่
